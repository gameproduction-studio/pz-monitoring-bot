# Тесты первой версии

Цель: Project Zomboid 42.20.3 Stable. Дата: 2026-08-21.

Проверена цепочка из четырёх снимков: появление - `incoming`; перемещение того
же itemId - только `move`; разморозка - `food_thawed`; исчезновение из
перечитанной полки - `outgoing`.

Также проверены вложенные контейнеры, stale-данные без дубликатов, condition,
калории из игры, отсутствие напоминаний про электричество, EvolvedRecipe,
создание live-файлов и локальной точки сравнения. Поиск выбирает сначала
максимальную вместимость рюкзака, затем ближайший экземпляр.

Команда: `cd app; python -m pytest -q`.

Добавлены тесты автомобилей: принадлежность груза, перенос выгруженной машины
как stale без ложного расхода, безопасное удаление записи, события топлива,
движения, общего condition и отдельной детали, а также предупреждение при 24%
топлива. Проверено отсутствие кадровых и минутных обработчиков.

Полный опубликованный снимок из 1229 предметов занимал 6 512 904 байта и
превысил лимит источника обычного ChatGPT. Новый компактный контракт на том же
снимке оценивается в 2 442 788 байт: дублирующий плоский список удалён, JSON
записывается без отступов, факты мира и `assistantViews` сохранены.

Результат: 29 тестов успешно. Автомобильная логика доказана на синтетических
последовательных снимках; фактический runtime-снимок конкретной машины должен
быть подтверждён первым тестом в игре после установки этой версии.
