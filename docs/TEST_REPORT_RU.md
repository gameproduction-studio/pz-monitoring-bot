# Тесты первой версии

Цель: Project Zomboid 42.20.3 Stable. Дата: 2026-08-21.

Проверена цепочка из четырёх снимков: появление - `incoming`; перемещение того
же itemId - только `move`; разморозка - `food_thawed`; исчезновение из
перечитанной полки - `outgoing`.

Также проверены вложенные контейнеры, stale-данные без дубликатов, condition,
калории из игры, отсутствие напоминаний про электричество, EvolvedRecipe,
создание live-файлов и локальной точки сравнения. Поиск выбирает сначала
максимальную вместимость рюкзака, затем ближайший экземпляр.

Команда: `cd app; python -m pytest -q`.

Результат: 17 тестов успешно. Это доказательство на синтетических снимках.
Реальная загрузка мода игрой обязательна до постоянного автопуша. Watcher не
оставлен работающим.
